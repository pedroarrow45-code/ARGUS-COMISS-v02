# ARGUS GROUP Performance Hub

Base de plataforma web em Next.js para gestao de resultados empresariais da ARGUS GROUP.

## Stack

- Next.js
- React
- Tailwind CSS
- Zustand

## Como rodar

```bash
npm install
npm run dev
```

## Estrutura

- `src/app`: rotas e layout principal
- `src/components`: componentes de UI e blocos visuais
- `src/features`: regras de negocio e calculos do dashboard
- `src/store`: estado global com projetos mockados
- `src/data`: dados iniciais mockados
- `src/types`: tipos compartilhados
